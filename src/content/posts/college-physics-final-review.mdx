### 二、核心公式清单

| 公式 | 说明 | 易错点 |
|:---|:---|:---|
| $F = \frac{1}{4\pi\varepsilon_0}\frac{q_1 q_2}{r^2}$ | 库仑定律（静止点电荷） | 方向沿连线，同斥异吸 |
| $E = \frac{F}{q_0}$ | 电场强度定义 | 与试探电荷无关 |
| $E = \int \frac{\mathrm{d}q}{4\pi\varepsilon_0 r^2}\hat{r}$ | 连续带电体电场叠加 | 矢量叠加需分解分量 |
| $\Phi_e = \oint E\cdot\mathrm{d}S = \frac{Q_{内}}{\varepsilon_0}$ | 高斯定理 | 只适用于高度对称情况 |
| $\oint E\cdot\mathrm{d}l = 0$ | 静电场环路定理 | 静电场是保守场 |
| $V_b - V_a = -\int_a^b E\cdot\mathrm{d}l$ | 电势差定义 | 积分路径无关 |
| $V = \frac{1}{4\pi\varepsilon_0}\frac{q}{r}$ | 点电荷电势 | 无穷远为零点 |
| $E = -\nabla V$ | 电势梯度 | 负号！指向电势降低方向 |
| $W = q(V_a - V_b)$ | 电场力做功 | 正电荷从高电势到低电势做正功 |

### 三、题型分类与解题技巧

#### 第一类：库仑定律与点电荷受力

**解题步骤：**

| 步骤 | 操作 | 关键点 |
|:---|:---|:---|
| 1 | 画受力图 | 判断每个库仑力是吸引还是排斥 |
| 2 | 分别求大小 | 用 $F = k\frac{q_1 q_2}{r^2}$ 计算每个力的大小 |
| 3 | 分解到坐标轴 | 建立坐标系，将各力分解 |
| 4 | 求合力 | 对每个分量求和 |
| 5 | 若有平衡条件 | $\sum F_x = 0$, $\sum F_y = 0$ |

**常见题型：**
- 两个点电荷之间的库仑力
- 三个点电荷的合力和平衡问题
- 带电小球在重力+库仑力下的平衡

**易错点：**
- ⚠️ 方向：$F_{12}$ 是 $q_2$ 对 $q_1$ 的力，方向由 $q_2$ 指向 $q_1$
- ⚠️ 库仑定律只适用于点电荷，带电体不能看作点电荷时需用微积分
- ⚠️ 多个点电荷作用时满足力的叠加原理（矢量加法）

#### 第二类：电场强度计算

**a) 点电荷系的电场：**

$$E = \sum_i \frac{1}{4\pi\varepsilon_0}\frac{q_i}{r_i^2}\hat{r}_i$$

**b) 连续带电体的电场：**

基本步骤：
1. 取电荷元 $\mathrm{d}q$
2. 写出 $\mathrm{d}E = \frac{\mathrm{d}q}{4\pi\varepsilon_0 r^2}\hat{r}$
3. 分解为分量：$\mathrm{d}E_x$, $\mathrm{d}E_y$
4. 积分求合场

**常见连续带电体模型：**

| 模型 | 电荷元取法 | 对称性分析 | 关键积分 |
|:---|:---|:---|:---|
| **均匀带电直线** | $\mathrm{d}q = \lambda\mathrm{d}l$ | 轴向分量对称相消 | $\int \frac{\lambda\mathrm{d}l}{4\pi\varepsilon_0 r^2}\cos\theta$ |
| **均匀带电圆环轴线** | $\mathrm{d}q = \lambda\mathrm{d}l$ | 垂直分量对称相消 | $E = \frac{qx}{4\pi\varepsilon_0 (R^2+x^2)^{3/2}}$ |
| **均匀带电圆盘轴线** | $\mathrm{d}q = \sigma\cdot 2\pi r'\mathrm{d}r'$ | 同心细环叠加 | $E = \frac{\sigma}{2\varepsilon_0}\left(1 - \frac{x}{\sqrt{R^2+x^2}}\right)$ |
| **无限大带电平面** | — | — | $E = \frac{\sigma}{2\varepsilon_0}$ |

**易错点：**
- ⚠️ 矢量叠加！不要忘记方向，分解到坐标轴
- ⚠️ 均匀带电圆环在圆心处 $E=0$（对称性）
- ⚠️ 无限大平板两侧场强大小相等，但方向相反

#### 第三类：高斯定理求电场

**适用条件：** 电荷分布具有高度对称性（球对称、轴对称、面对称）

**解题步骤：**

| 步骤 | 操作 |
|:---|:---|
| 1 | 分析对称性：判断E的方向 |
| 2 | 选高斯面：使面上E等大且与面法向平行或垂直 |
| 3 | 计算高斯面内的总电荷 $Q_{内}$ |
| 4 | 代入 $\oint E\cdot\mathrm{d}S = Q_{内}/\varepsilon_0$ 求解E |
| 5 | 分区域讨论（如有多个区域） |

**高斯定理不能用的场景（不对称为例外）：**
- 非均匀球对称
- 有限长带电直线
- 非对称的带电体

**高频模型结果：**

| 模型 | $E$ 表达式 | 特征 |
|:---|:---|:---|
| **均匀带电球面（半径R）** | $r < R$: $E=0$; $r > R$: $E = \frac{Q}{4\pi\varepsilon_0 r^2}$ | 球面外等效于点电荷 |
| **均匀带电球体（半径R）** | $r < R$: $E = \frac{Qr}{4\pi\varepsilon_0 R^3}$; $r > R$: $E = \frac{Q}{4\pi\varepsilon_0 r^2}$ | 内部线性增长 |
| **无限长均匀带电直线** | $E = \frac{\lambda}{2\pi\varepsilon_0 r}$ | 柱对称，与1/r成正比 |
| **无限长均匀带电圆柱面** | $r < R$: $E=0$; $r > R$: $E = \frac{\lambda}{2\pi\varepsilon_0 r}$ | 内部为零 |
| **无限大均匀带电平面** | $E = \frac{\sigma}{2\varepsilon_0}$ | 与距离无关！ |
| **两平行无限大平面（等量异号）** | 中间: $E = \frac{\sigma}{\varepsilon_0}$; 外部: $E=0$ | 电容器模型 |

**易错点：**
- ⚠️ 高斯定理中的 $E$ 是**总电场**，由高斯面内外所有电荷共同产生；但通量只由面内电荷决定
- ⚠️ 不能直接用高斯定理的场景不要硬用——比如有限长直线，老老实实积分
- ⚠️ 画高斯面时注意对称性匹配：球对称→球面，柱对称→圆柱面，面对称→柱面

#### 3a. 课后题常见分类（高斯定理）

| 题型 | 出题方式 | 解题关键 |
|:---|:---|:---|
| **通量判断题** | 点电荷在闭合面内/外，求通量 | 只看 $q_{内}$，不看曲面形状 |
| **开曲面通量** | 匀强场穿过三角形、圆面、斜面 | 用 $\Phi = ES\cos\theta$ |
| **球对称求场** | 球面、球体、球壳分段 | $Q_{内}$ 要随 $r$ 变化 |
| **柱对称求场** | 无限长线、电缆、圆柱面 | 高斯面用同轴圆柱 |
| **面对称求场** | 无限大平面、双平板 | 高斯面用薄柱盒 |
| **叠加+高斯** | 挖空球、带孔平面 | 补全再减去（"负电荷"法） |


#### 第四类：电势与电势能

**求电势的两种方法：**

1. **电场积分法：** $V_P = -\int_\infty^P E\cdot\mathrm{d}l$
   - 先求E，再沿任意路径积分
   - 若E分段，需分段积分

2. **电荷叠加法：** $V = \int \frac{\mathrm{d}q}{4\pi\varepsilon_0 r}$
   - 直接对电荷元积分
   - 标量叠加，不要分解方向（比求E简单）

**常见带电体的电势：**

| 模型 | 电势分布 |
|:---|:---|
| 点电荷 | $V = \frac{q}{4\pi\varepsilon_0 r}$ |
| 均匀带电球面（r ≤ R） | $V = \frac{Q}{4\pi\varepsilon_0 R}$（等势！） |
| 均匀带电球面（r > R） | $V = \frac{Q}{4\pi\varepsilon_0 r}$ |
| 无限长均匀带电直线 | $V = \frac{\lambda}{2\pi\varepsilon_0}\ln\frac{r_0}{r}$（需选参考点） |

**电场力做功：**
$$W_{ab} = q(V_a - V_b) = \frac{1}{2}mv_b^2 - \frac{1}{2}mv_a^2$$

**易错点：**
- ⚠️ 电势是标量，叠加时直接代数相加（带正负号！）
- ⚠️ 电势零点：点电荷和有限带电体取无穷远；无限长带电体不能取无穷远
- ⚠️ $V = \int \frac{\mathrm{d}q}{4\pi\varepsilon_0 r}$ 中 $r$ 是电荷元到场点的距离，不是积分变量

### 四、典型例题


#### 第五类题：电势、电势差与电势叠加

电势是标量，比电场强度更容易叠加。定义为：

$$V_A = \frac{E_{pA}}{q_0}$$

若选无穷远处为零电势：

$$V_A = \int_A^\infty E\cdot\mathrm{d}l$$

电势差：

$$V_A - V_B = \int_A^B E\cdot\mathrm{d}l$$

**1. 点电荷电势**
$$V = \frac{1}{4\pi\varepsilon_0}\frac{q}{r}$$

注意：电势有正负，正电荷产生正电势，负电荷产生负电势。

**2. 点电荷系电势**
$$V = \sum_i \frac{1}{4\pi\varepsilon_0}\frac{q_i}{r_i}$$

这里是**代数和**，不是矢量和。

**3. 连续带电体电势**
$$\mathrm{d}V = \frac{1}{4\pi\varepsilon_0}\frac{\mathrm{d}q}{r}$$
$$V = \int\mathrm{d}V = \frac{1}{4\pi\varepsilon_0}\int\frac{\mathrm{d}q}{r}$$

**4. 必会模型**

| 模型 | 电势结果 |
|:---|:---|
| 点电荷 | $V = \frac{1}{4\pi\varepsilon_0}\frac{q}{r}$ |
| 均匀带电圆环轴线上 | $V = \frac{1}{4\pi\varepsilon_0}\frac{Q}{\sqrt{R^2 + x^2}}$ |
| 均匀带电球面 | $r>R$: $V = \frac{Q}{4\pi\varepsilon_0 r}$, $r<R$: $V = \frac{Q}{4\pi\varepsilon_0 R}$ |
| 均匀带电球体 | $r>R$: $V = \frac{Q}{4\pi\varepsilon_0 r}$, $r<R$: $V = \frac{Q}{8\pi\varepsilon_0 R}(3 - \frac{r^2}{R^2})$ |
| 无限长带电直线 | 不能直接选 $V_\infty=0$，一般求电势差 |

**5. 电势题的两个方法**

| 方法 | 适用情况 | 公式 |
|:---|:---|:---|
| **电势叠加法** | 已知电荷分布，求某点电势 | $V = \int \frac{1}{4\pi\varepsilon_0}\frac{\mathrm{d}q}{r}$ |
| **场强积分法** | 已由高斯定理求出E | $V_A - V_B = \int_A^B E\cdot\mathrm{d}l$ |

求电势常用两种方法：已知电荷分布时用电势叠加，若E容易由高斯定理求出，则用场强积分法。

#### 第六类题：等势面与电势梯度

等势面是电势相同的点构成的面。沿等势面移动电荷时：

$$W = q\Delta V = 0$$

所以电场力不做功。不同电势的等势面不能相交，电场线与等势面垂直，并且电场方向指向电势降低方向。

**1. 核心公式**
$$E = -\nabla V$$

直角坐标系中：
$$E = -\left(\frac{\partial V}{\partial x}\hat{i} + \frac{\partial V}{\partial y}\hat{j} + \frac{\partial V}{\partial z}\hat{k}\right)$$

若电势只沿x方向变化：
$$E_x = -\frac{\mathrm{d}V}{\mathrm{d}x}$$

**2. 常考形式**

| 题型 | 解法 |
|:---|:---|
| 给出 $V = ax + by + cz$，求 $E$ | 对x,y,z分别求偏导，再加负号 |
| 给出 $V(r)$，求径向电场 | $E_r = -\frac{\mathrm{d}V}{\mathrm{d}r}$ |
| 已知等势面疏密判断场强大小 | 等势面越密，场强越大 |
| 判断场强方向 | 从高电势指向低电势，并垂直等势面 |
| 由圆环轴线电势求电场 | 先写 $V(x)$，再 $E_x = -\mathrm{d}V/\mathrm{d}x$ |

**3. 典型例子：圆环轴线场强**

已知：
$$V(x) = \frac{1}{4\pi\varepsilon_0}\frac{Q}{\sqrt{R^2 + x^2}}$$

则：
$$E_x = -\frac{\mathrm{d}V}{\mathrm{d}x} = \frac{1}{4\pi\varepsilon_0}\frac{Qx}{(R^2 + x^2)^{3/2}}$$

这个题型非常实用：先求标量电势，再求导得到矢量电场，比直接积分电场更省力。

#### 第七类题：电偶极子

电偶极子由一对等量异号点电荷组成，电偶极矩定义为：

$$p = ql$$

方向从**负电荷指向正电荷**。

**1. 电偶极子远处电势**

当场点距离 $r \gg l$：
$$V = \frac{1}{4\pi\varepsilon_0}\frac{p\cos\theta}{r^2}$$

其中 $\theta$ 是 $p$ 与场点位置矢量 $r$ 的夹角。

**2. 电偶极子远处电场**

球坐标分量：
$$E_r = \frac{1}{4\pi\varepsilon_0}\frac{2p\cos\theta}{r^3}$$
$$E_\theta = \frac{1}{4\pi\varepsilon_0}\frac{p\sin\theta}{r^3}$$

特殊位置：

| 位置 | 电场大小 |
|:---|:---|
| 轴线上 | $E = \frac{1}{4\pi\varepsilon_0}\frac{2p}{r^3}$ |
| 中垂线上 | $E = \frac{1}{4\pi\varepsilon_0}\frac{p}{r^3}$，方向与 $p$ 相反 |

**3. 均匀外电场中的力矩与势能**
$$M = p \times E$$
大小：$M = pE\sin\theta$

势能：
$$U = -p\cdot E = -pE\cos\theta$$

| 状态 | 条件 | 稳定性 |
|:---|:---|:---|
| $p \parallel E$ | $\theta = 0$ | 稳定平衡，势能最低 |
| $p$ 反平行 $E$ | $\theta = \pi$ | 不稳定平衡，势能最高 |
| 其他角度 | $0 < \theta < \pi$ | 受力矩转向 |

**例题1：** 均匀带电细棒长 $L$，电荷线密度 $\lambda$，求棒延长线上距离一端 $a$ 处的电场强度。

**解：**
1. 取坐标：棒沿x轴从0到L，场点在x = L + a处
2. 取电荷元 $\mathrm{d}q = \lambda\mathrm{d}x$，距离场点 $r = L + a - x$
3. $\mathrm{d}E = \frac{1}{4\pi\varepsilon_0}\frac{\lambda\mathrm{d}x}{(L+a-x)^2}$
4. 积分：
   $$E = \frac{\lambda}{4\pi\varepsilon_0}\int_0^L \frac{\mathrm{d}x}{(L+a-x)^2} = \frac{\lambda}{4\pi\varepsilon_0}\left(\frac{1}{a} - \frac{1}{L+a}\right)$$
5. 方向沿x轴正向（远离棒）

**例题2：** 求均匀带电球体（半径R，总电荷Q）的电场分布。

**解：**
由球对称，选同心球面为高斯面。

**r < R（内部）：**
- $Q_{内} = Q\frac{r^3}{R^3}$
- $\oint E\cdot\mathrm{d}S = E\cdot 4\pi r^2 = \frac{Q_{内}}{\varepsilon_0} = \frac{Q r^3}{\varepsilon_0 R^3}$
- $E = \frac{Q r}{4\pi\varepsilon_0 R^3}$（与r成正比）

**r > R（外部）：**
- $Q_{内} = Q$
- $E\cdot 4\pi r^2 = \frac{Q}{\varepsilon_0}$
- $E = \frac{Q}{4\pi\varepsilon_0 r^2}$（等效于点电荷）


### 五、高斯定理求电场模板

**模板1：均匀带电球体求 $E(r)$**

半径R，总电荷Q，体电荷密度均匀。

球外 $r > R$：
$$E \cdot 4\pi r^2 = \frac{Q}{\varepsilon_0} \quad \Rightarrow \quad E = \frac{1}{4\pi\varepsilon_0}\frac{Q}{r^2}$$

球内 $r < R$：
$$q_{内} = Q\frac{r^3}{R^3}$$
$$E \cdot 4\pi r^2 = \frac{Q r^3/R^3}{\varepsilon_0} \quad \Rightarrow \quad E = \frac{1}{4\pi\varepsilon_0}\frac{Qr}{R^3}$$

结论：球内 $E \propto r$，球外 $E \propto 1/r^2$。

**模板2：无限长带电直线求 $E(r)$**

取半径 $r$、长度 $l$ 的同轴圆柱面：
$$\Phi = E \cdot 2\pi rl$$
$$q_{内} = \lambda l$$
$$E \cdot 2\pi rl = \frac{\lambda l}{\varepsilon_0} \quad \Rightarrow \quad E = \frac{\lambda}{2\pi\varepsilon_0 r}$$

方向：$\lambda > 0$ 时径向向外。

**模板3：无限大带电平面求 $E$**

取穿过平面的薄柱盒，高斯面两端面积为 $S$：
$$\Phi = 2ES$$
$$q_{内} = \sigma S$$
$$2ES = \frac{\sigma S}{\varepsilon_0} \quad \Rightarrow \quad E = \frac{\sigma}{2\varepsilon_0}$$

方向：正电荷两侧均背离平面。

**模板4：点电荷系求电势**

几个点电荷 $q_i$ 到场点距离 $r_i$：
$$V = \sum_i \frac{1}{4\pi\varepsilon_0} \frac{q_i}{r_i}$$

注意这里不分方向，只保留电荷正负号。

**模板5：电场力做功**

电荷 $q_0$ 从A点移到B点：
$$W_{AB} = q_0(V_A - V_B)$$
$$\Delta E_p = E_{pB} - E_{pA} = -W_{AB}$$

若正电荷从高电势到低电势，电场力做正功，电势能减少。

### 三、题型分类与解题技巧

#### 第一类：导体静电平衡

**四个硬结论：**

1. 导体内部 $E = 0$
2. 导体是等势体，表面是等势面
3. 电荷只分布在**表面**
4. 表面外紧邻处 $E = \sigma/\varepsilon_0$，方向垂直表面

**空腔导体电荷分布规律：**

| 情况 | 电荷分布结论 |
|:---|:---|
| 实心导体带电Q | 净电荷只分布在外表面 |
| 空腔导体，腔内无电荷 | 内表面无电荷，净电荷分布在外表面 |
| 空腔导体，腔内有电荷q | 内表面感应出 -q，外表面为 $Q_{总}+q$ |

**解题三件套：** 电荷守恒 + 静电平衡条件($E_{内}=0$) + 高斯定理

**解题标准流程：**

| 步骤 | 操作 |
|:---|:---|
| 1 | 判断导体是否达到静电平衡 |
| 2 | 利用 $E_{内}=0$ 和电荷守恒列方程 |
| 3 | 求各表面电荷分布 |
| 4 | 选高斯面 → 分区求E → 积分求U |
| 5 | 接地条件：$U=0$ |

**易错点：**
- ⚠️ 接地后电势为零，但电荷不一定为零
- ⚠️ 静电平衡内部 $E=0$ 是总电场为零，不是没有电场贡献
- ⚠️ 空腔导体对外部有静电屏蔽作用，但外部对腔内无影响（仅当腔外无电荷时）

#### 1a. 导体接地题的本质（核心方法）

接地不是"电荷变零"，而是**电势变零**。这是第六章最容易错的地方。接地导体可以从大地得到电荷，也可以把电荷流向大地，所以接地导体本身的总电荷一般不能提前假设。

**解题标准顺序（四步法）：**

| 步骤 | 操作 | 说明 |
|:---|:---|:---|
| 1 | **画导体表面** | 球壳要分内表面、外表面；金属板要分左表面、右表面 |
| 2 | **设未知电荷或面密度** | 如 $q_1, q_2$ 或 $\sigma_1, \sigma_2, \sigma_3, \sigma_4$ |
| 3 | **写导体内部 $E=0$** | 这是最强约束条件，由叠加原理列方程 |
| 4 | **用电势条件** | 接地 $\Rightarrow V=0$；未接地导体用电荷守恒 |

**常见题型——需要设未知面密度的模型：**

**(1) 多层金属板（三块或以上）**

三块平行金属板，从左到右分别带电 $Q_1, Q_2, Q_3$，每块板有两个表面，共设6个面密度 $\sigma_1 \sim \sigma_6$。

列方程的思路：
- 每块板内部 $E=0$（无限大平面场强叠加）→ 3个方程
- 每块板电荷守恒：$\sigma_{左}S + \sigma_{右}S = Q$ → 3个方程
- 若某板接地 → $V=0$ 替换对应的电荷守恒方程

**(2) 同心导体球壳（含接地）**

内球半径 $a$，带电 $Q$；外球壳内外半径 $b, c$，原先带电 $Q_0$（或接地）。设：
- 内球表面：$q_a = Q$
- 外球壳内表面：$q_b$（未知）
- 外球壳外表面：$q_c$（未知）

列方程：
- 球壳内部 $E=0$（高斯定理 + 内部电场为零）
- 球壳电荷守恒：$q_b + q_c = Q_0$
- 若接地：$V_{壳}=0$

**(3) 平行板电容器插入金属板**

两极板间插入一块厚度为 $t$ 的金属板，需设金属板两侧的感应电荷面密度。

**四步法应用示例：同心导体球壳接地**

> **题目：** 内球半径 $a$，电荷 $+Q$；外球壳半径 $b$（内）、$c$（外），不带电且**接地**。求各表面电荷分布。

**解（四步法）：**

**① 画表面：** 三个表面——内球表面(1)、外球壳内表面(2)、外球壳外表面(3)

**② 设电荷：** 设 $q_1 = Q$（已知），$q_2$（待求），$q_3$（待求）

**③ 内部 $E=0$：** 在外球壳内部（$b < r < c$）取高斯面，由于该区域在导体内部，$E=0$，所以：
$$\oint E\cdot\mathrm{d}S = 0 \quad\Rightarrow\quad q_1 + q_2 = 0 \quad\Rightarrow\quad q_2 = -Q$$

**④ 接地条件：** 外球壳接地，$V_{壳}=0$。外球壳电势由三部分电荷叠加：
$$V_{壳} = \frac{1}{4\pi\varepsilon_0}\left(\frac{Q}{b} + \frac{-Q}{b} + \frac{q_3}{c}\right) = \frac{1}{4\pi\varepsilon_0}\frac{q_3}{c} = 0 \quad\Rightarrow\quad q_3 = 0$$

**结论：** 内球 $+Q$，外球壳内表面 $-Q$，外表面 $0$（电荷全部跑向大地）。

这个结果直观理解：接地后外球壳外表面电荷全部导入大地，因为外表面电荷对外没有约束。

**易错点：**
- ⚠️ 接地不是"电荷归零"，而是"电势为零"——本例中 $q_3=0$ 是电势条件的结果，不是假设
- ⚠️ 未接地时不能直接用电荷守恒代替电势条件
- ⚠️ 球壳接地后，若内部有电荷，内表面仍然会感应出等量异号电荷

#### 第二类：有电介质的高斯定理

**标准流程（正确顺序）：**

$$
\text{自由电荷} \xrightarrow{\text{有介质高斯定理}} D \xrightarrow{D = \varepsilon E} E \xrightarrow{P = D - \varepsilon_0 E} P \xrightarrow{\sigma' = P\cdot\hat{n}} \sigma'
$$

详细步骤：

| 步骤 | 操作 | 公式 | 说明 |
|:---|:---|:---|:---|
| 1 | 由自由电荷对称性，求 $D$ | $\oint D\cdot\mathrm{d}S = Q_{自由}$ | 自由电荷是"源" |
| 2 | 由 $D$ 反推 $E$ | $E = D/\varepsilon = D/(\varepsilon_0\varepsilon_r)$ | 介质削弱电场 |
| 3 | 由 $D$ 和 $E$ 求极化强度 $P$ | $P = D - \varepsilon_0 E$ | 描述介质极化程度 |
| 4 | 由 $P$ 求束缚电荷面密度 | $\sigma' = P\cdot\hat{n}$ | $\hat{n}$ 是介质表面外法向 |

**关键解释：$\sigma' = P\cdot\hat{n}$ 是什么意思？**

- $P$ 是"极化强度"矢量，描述介质内部电偶极矩的密度（单位体积内电偶极矩的矢量和）
- $\hat{n}$ 是介质表面的**外法线方向**（从介质指向外）
- $P\cdot\hat{n}$ 是 $P$ 在 $\hat{n}$ 方向上的投影，即 $P$ 垂直于表面的分量

**物理含义：**
- 若 $P$ 与 $\hat{n}$ 同向（$P$ 指向外），$\sigma' > 0$，表面出现**正**束缚电荷
- 若 $P$ 与 $\hat{n}$ 反向（$P$ 指向内），$\sigma' < 0$，表面出现**负**束缚电荷
- 束缚电荷来源于介质极化后正负电荷中心的微小错位，不能自由移动

**两种求 $P$ 的等价公式：**

| 公式 | 适用 | 含义 |
|:---|:---|:---|
| $P = D - \varepsilon_0 E$ | **通用**（任何介质） | 从已知的 D、E 直接算 |
| $P = \varepsilon_0\chi_e E$ | 仅各向同性线性介质 | 引入极化率 $\chi_e = \varepsilon_r - 1$ |

**注意：** $P = D - \varepsilon_0 E$ 是更基本的定义式，**不需要知道 $\chi_e$**，只要算出 D 和 E 就能直接得到 P。而 $P = \varepsilon_0\chi_e E$ 需要已知 $\chi_e$ 或 $\varepsilon_r$。

**对比：**

| | 无介质（真空） | 有各向同性介质 |
|:---|:---|:---|
| 高斯定理 | $\oint E\cdot\mathrm{d}S = Q/\varepsilon_0$ | $\oint D\cdot\mathrm{d}S = Q_{自由}$ |
| 场量 | $E$ | 先 $D$ 后 $E = D/\varepsilon$ |
| 电荷 | 只有自由电荷 | 自由+束缚，但只用自由电荷算D |

**易错点：**
- ⚠️ 有介质时不能直接用真空高斯定理求E！必须先求D
- ⚠️ $\varepsilon = \varepsilon_0\varepsilon_r$，$\varepsilon_r = 1 + \chi_e$
- ⚠️ 束缚电荷产生的电场与自由电荷相反，总电场被削弱

#### 2a. 电位移通量中的"两倍面积"问题详解

在用 $D$ 的高斯定理求介质中的场时，**取高斯面（薄柱盒/药盒形）穿过界面**的情况最容易出错，核心在于**高斯面有几个端面贡献通量**。

**场景1：无限大带电平面 ± 一侧有介质（药盒穿过平面）**

高斯面取为穿过带电平面的薄柱盒，两个端面分别在平面两侧，面积均为 $S$。

$$\oint D\cdot\mathrm{d}S = D_1S + D_2S = Q_{自由}$$

- 若两侧介质相同，则 $D_1 = D_2 = D$，$2DS = \sigma_f S$ → $D = \dfrac{\sigma_f}{2}$
- 若一侧是真空、一侧是介质，则 $D$ 虽然连续（法向分量相等），但 $E$ 不同

**这里出现"2"的原因：** 高斯面有两个端面都在场中，每个端面贡献 $D\cdot S$，所以总和是 $2DS$。

**场景2：导体-介质界面（药盒一端在导体内）**

高斯面一端在导体内部（$E=0, D=0$），另一端在介质中，面积为 $S$。

$$\oint D\cdot\mathrm{d}S = D\cdot S + 0 = \sigma_f S \quad\Rightarrow\quad D = \sigma_f$$

**这里没有"2"的原因：** 导体内部 $D=0$，高斯面只有一端有通量贡献。

**场景3：两种介质的分界面（药盒穿过界面）**

高斯面穿过两种不同介质的交界面，两个端面分别在介质1和介质2中，面积均为 $S$。

$$\oint D\cdot\mathrm{d}S = D_1S\cos\theta_1 + D_2S\cos\theta_2 = Q_{自由}$$

若界面上无自由电荷（$Q_{自由}=0$），则：

$$D_1\cos\theta_1 = D_2\cos\theta_2 \quad\Rightarrow\quad D_{1n} = D_{2n}$$

即 $D$ 的法向分量在界面上连续（无自由电荷时）。

**判断口诀：**

| 高斯面位置 | 几个端面贡献通量 | 公式形式 |
|:---|:---:|:---|
| 穿过自由电荷平面（两侧都有场） | 2个 | $2DS = \sigma_f S$ |
| 一端在导体内，一端在介质中 | 1个 | $DS = \sigma_f S$ |
| 穿过两种介质分界面 | 2个 | $D_{1n} = D_{2n}$（无自由电荷） |

**核心思想：** 画高斯面时，**先判断哪些面上 $D$ 不为零且与面法向平行**，这些面才贡献通量。不要默认"两个端面都有"或"只有一个端面有"。

#### 第三类：电容器

**求电容的通用步骤：**

1. 设两极板带电荷 $+Q$, $-Q$
2. 用高斯定理求 $E$（通常分区域）
3. 积分求电压 $U = \int E\cdot\mathrm{d}l$
4. $C = Q/U$

**三种典型电容器：**

| 电容器 | 电容公式 | 适用条件 |
|:---|:---|:---|
| 平行板电容器 | $C = \frac{\varepsilon S}{d} = \frac{\varepsilon_0\varepsilon_r S}{d}$ | 忽略边缘效应 |
| 圆柱形电容器 | $C = \frac{2\pi\varepsilon l}{\ln(R_2/R_1)} = \frac{2\pi\varepsilon_0\varepsilon_r l}{\ln(b/a)}$ | 同轴长圆柱 |
| 球形电容器 | $C = 4\pi\varepsilon\frac{R_1 R_2}{R_2 - R_1} = 4\pi\varepsilon_0\varepsilon_r\frac{ab}{b-a}$ | 同心球壳 |
| 孤立导体球 | $C = 4\pi\varepsilon R$（外球半径 $R_2 \to \infty$） | 球形电容器外半径无穷大的极限 |

**注意：** 孤立导体球可视为球形电容器 $R_2 \to \infty$ 的极限：
$$C = \lim_{R_2\to\infty} 4\pi\varepsilon\frac{R_1 R_2}{R_2 - R_1} = 4\pi\varepsilon R_1$$

**电容器串并联：**

- **串联：** $\frac{1}{C} = \frac{1}{C_1} + \frac{1}{C_2}$，各极板 $Q$ 相同，$U$ 分配与 $C$ 成反比
- **并联：** $C = C_1 + C_2$，各极板 $U$ 相同，$Q$ 分配与 $C$ 成正比

#### 第四类：静电场能量

**1. 电容器储能公式（三式等价）**

$$W = \frac{1}{2}QU = \frac{1}{2}CU^2 = \frac{Q^2}{2C}$$

三式等价，但选哪一个取决于题目给什么、固定什么：

| 固定条件 | 优先用 | 说明 |
|:---|:---|:---|
| 固定 $Q$（断开电源） | $W = \dfrac{Q^2}{2C}$ | 改变C时，直接用Q不变 |
| 固定 $U$（接通电源） | $W = \dfrac{1}{2}CU^2$ | 改变C时，直接用U不变 |
| 已知场分布（非电容器） | $W = \displaystyle\int \frac{1}{2}\varepsilon E^2\,\mathrm{d}V$ | 对电场空间积分 |

**注意：** 对于球形、圆柱形电容器，若题目要求"从能量密度出发求能量"，**不能直接套** $\frac{1}{2}CU^2$，而要先求 $E(r)$，再对空间积分。

**2. 电场能量密度**

线性介质中：
$$w_e = \frac{1}{2}\varepsilon E^2 = \frac{1}{2}E\cdot D$$

总能量通过对电场空间的体积分得到：
$$W_e = \int_V w_e\,\mathrm{d}V = \int_V \frac{1}{2}\varepsilon E^2\,\mathrm{d}V$$

**例题：** 求球形电容器的电场能量（从场积分出发）

球形电容器内半径 $R_1$、外半径 $R_2$，带电荷 $\pm Q$，介质 $\varepsilon$。

**解：**
① 由高斯定理求 $E(r)$：
$$E(r) = \frac{Q}{4\pi\varepsilon r^2} \quad (R_1 < r < R_2)$$

② 能量密度：
$$w_e = \frac{1}{2}\varepsilon E^2 = \frac{1}{2}\varepsilon\left(\frac{Q}{4\pi\varepsilon r^2}\right)^2 = \frac{Q^2}{32\pi^2\varepsilon r^4}$$

③ 对球形壳层体积分：
$$W_e = \int_{R_1}^{R_2} w_e\cdot 4\pi r^2\,\mathrm{d}r = \int_{R_1}^{R_2} \frac{Q^2}{32\pi^2\varepsilon r^4}\cdot 4\pi r^2\,\mathrm{d}r = \frac{Q^2}{8\pi\varepsilon}\int_{R_1}^{R_2}\frac{\mathrm{d}r}{r^2}$$

$$W_e = \frac{Q^2}{8\pi\varepsilon}\left(\frac{1}{R_1} - \frac{1}{R_2}\right) = \frac{1}{2}\cdot\frac{Q^2}{4\pi\varepsilon\frac{R_1 R_2}{R_2-R_1}} = \frac{Q^2}{2C}$$

结果与 $\dfrac{Q^2}{2C}$ 一致，验证了能量密度积分法的正确性。

**3. 能量变化分析**

| 条件 | 操作 | 关键公式 |
|:---|:---|:---|
| 电源断开（Q不变） | Q固定，改变C | $W = \dfrac{Q^2}{2C}$ |
| 电源接通（U不变） | U固定，改变C | $W = \dfrac{1}{2}CU^2$ |

**经典问题：** 插入介质板

- **Q不变（断开电源）：** 插入介质 → C增大 → $W = Q^2/(2C)$ 减小 → 电场能量减少（介质被吸入，电场力做正功）
- **U不变（接通电源）：** 插入介质 → C增大 → $W = CU^2/2$ 增大 → 电源做功给电容器充电（介质仍然被吸入）

## 第七章 恒定磁场

### 一、知识框架

| 模块 | 核心公式 | 题型 |
|:---|:---|:---|
| **7-1 恒定电流** | $I = dq/dt$, $I = \int j\cdot\mathrm{d}S$, $j = nqv_d$, $j = \sigma E$ | 电流密度、漂移速率 |
| **7-2 电源与电动势** | $\varepsilon = \int K\cdot\mathrm{d}l/q = \int E_{非}\cdot\mathrm{d}l$ | 电动势方向 |
| **7-3 磁场与磁感强度** | $F = qv\times B$ | 洛伦兹力方向、粒子偏转 |
| **7-4 毕奥-萨伐尔定律** | $\mathrm{d}B = \frac{\mu_0}{4\pi}\frac{I\mathrm{d}l\times\hat{r}}{r^2}$ | 有限直线、圆弧、圆环、转动带电体求B |
| **7-5 磁通量与高斯定理** | $\Phi_m = \int B\cdot\mathrm{d}S$, $\oint B\cdot\mathrm{d}S = 0$ | 磁通量计算 |
| **7-6 安培环路定理** | $\oint B\cdot\mathrm{d}l = \mu_0\sum I_{内}$ | 长直导线、圆柱、螺绕环、载流平面 |
| **7-7 带电粒子运动** | $r = mv_\perp/\lvert q\rvert B$, $T = 2\pi m/\lvert q\rvert B$, $h = v_\parallel T$ | 圆周/螺旋运动、质谱仪、回旋加速器 |
| **7-8 磁场对电流作用** | $\mathrm{d}F = I\mathrm{d}l\times B$, $M = m\times B$, $m = NIS\hat{n}$ | 平行导线力、线圈受力、磁力矩 |
| **7-9 磁介质** | $H = B/\mu_0 - M$, $\oint H\cdot\mathrm{d}l = I_{自由}$, $B = \mu H$ | 同轴介质电缆、磁化强度 |

### 二、核心公式清单

| 公式 | 条件 | 易错点 |
|:---|:---|:---|
| $I = \int j\cdot\mathrm{d}S$ | 任意截面 | 若j不均匀，不能用 $I = jS$ |
| $j = \sigma E$ | 均匀各向同性导体 | 局域关系，非 $I = U/R$ |
| $F = qv\times B$ | 运动电荷 | 负电荷方向反转；磁力不做功 |
| $\mathrm{d}B = \frac{\mu_0}{4\pi}\frac{I\mathrm{d}l\times\hat{r}}{r^2}$ | 稳恒电流元 | 叉乘方向判断 |
| $\Phi_m = \int B\cdot\mathrm{d}S$ | 任意曲面 | 开曲面需规定法向 |
| $\oint B\cdot\mathrm{d}S = 0$ | 任意闭合曲面 | 净磁通为零，非 $B=0$ |
| $\oint B\cdot\mathrm{d}l = \mu_0 I_{内}$ | 稳恒电流 | B由所有电流产生，环流只由包围电流决定 |
| $\mathrm{d}F = I\mathrm{d}l\times B$ | 载流导线 | $\mathrm{d}l$ 方向沿电流 |
| $m = NIS\hat{n}$ | 平面线圈 | $\hat{n}$ 与电流右手螺旋 |
| $M = m\times B$ | 均匀磁场中线圈 | 稳定/不稳定平衡 |
| $\oint H\cdot\mathrm{d}l = I_{自由}$ | 磁介质中 | 先求H，再用 $B = \mu H$ |

### 三、求磁场的两条主线

| 对比 | 毕奥-萨伐尔定律 | 安培环路定理 |
|:---|:---|:---|
| **本质** | 电流元积分求磁场 | 环流与包围电流关系 |
| **适用** | 有限长导线、圆弧、组合导线、运动电荷 | 无限长直导线、圆柱、螺线管、载流平面 |
| **优势** | 通用，能处理非对称问题 | 快速，避免复杂积分 |
| **限制** | 积分方向易错 | 仅高对称性可用 |
| **口诀** | **不够对称，用毕奥；高度对称，用安培** |

### 常见磁场公式

| 电流分布 | 磁感强度 |
|:---|:---|
| 无限长直导线 | $B = \frac{\mu_0 I}{2\pi r}$ |
| 半无限长直导线端点 | $B = \frac{\mu_0 I}{4\pi r}$ |
| 有限长直导线 | $B = \frac{\mu_0 I}{4\pi a}(\sin\theta_1 + \sin\theta_2)$ |
| 圆电流轴线上 | $B = \frac{\mu_0 IR^2}{2(R^2 + x^2)^{3/2}}$ |
| 圆心处 | $B = \frac{\mu_0 I}{2R}$，N匝乘N |
| 圆弧圆心处 | $B = \frac{\mu_0 I\varphi}{4\pi R}$，$\varphi$ 用弧度 |
| 无限长螺线管内部 | $B = \mu_0 nI$ |
| 螺绕环内部 | $B = \frac{\mu_0 NI}{2\pi r}$ |
| 无限大载流平面单侧 | $B = \frac{\mu_0 K}{2}$ |

### 四、各节要点解析

#### 7-1 恒定电流
- 串联导体中I一定相同
- 截面积不同处j不同：$j = I/S$
- 材料相同截面不同处E不同：$j = \sigma E$
- **漂移速率：** $v_d = j/(nq)$，电子漂移速率远小于热运动速率
- **关键结论：** 电信号传播快 ≠ 电子漂移快

#### 7-3 洛伦兹力
- $v \parallel B$：$F=0$，不偏转
- $v \perp B$：匀速圆周，$r = mv/|q|B$
- $v$ 与 $B$ 有夹角：螺旋线
- 磁力永远不做功

#### 7-4 毕奥-萨伐尔定律

**做题模板：**
1. 取电流元 $I\mathrm{d}l$
2. 找几何关系：r、夹角θ
3. 判断方向：$\mathrm{d}l\times\hat{r}$
4. 写微元：$\mathrm{d}B = \frac{\mu_0}{4\pi}\frac{I\mathrm{d}l\sin\theta}{r^2}$
5. 积分或叠加，对称项相消

**组合导线题：**
- 直线段若场点在延长线上，贡献为零
- 圆弧段圆心处直接用 $B = \frac{\mu_0 I\varphi}{4\pi R}$

**转动带电体：**
- 带电圆环：$I = Q\omega/(2\pi)$
- 带电圆盘：分割成细圆环，$\mathrm{d}I = \sigma\omega r\mathrm{d}r$
- 圆盘中心磁场：$B = \mu_0\sigma\omega R/2$

#### 7-5 磁通量
- 均匀磁场：$\Phi_m = BS\cos\theta$（θ是B与面积矢量的夹角）
- 长直导线旁矩形磁通：$\Phi = \frac{\mu_0 I l}{2\pi}\ln\frac{a+b}{a}$

#### 7-6 安培环路定理

**解题步骤：**
1. 判断对称性
2. 选择安培环路（使B等大且与dl平行）
3. 计算包围电流 $I_{内}$
4. 代入 $\oint B\mathrm{d}l = \mu_0 I_{内}$
5. 分区域讨论，画B-r图

**高频模型：**

| 模型 | 内部 | 外部 |
|:---|:---|:---|
| 实心圆柱 | $B = \frac{\mu_0 I r}{2\pi R^2}$ | $B = \frac{\mu_0 I}{2\pi r}$ |
| 圆柱面 | $B = 0$ | $B = \frac{\mu_0 I}{2\pi r}$ |
| 同轴电缆 | 分四区 | 外导体外B=0（电流抵消） |
| 螺绕环 | $B = \frac{\mu_0 NI}{2\pi r}$ | 外部B=0 |
| 无限大载流平面 | 单侧 $B = \frac{\mu_0 K}{2}$ | 两侧方向相反 |
| 两平行载流平面（反向） | 中间 $B = \mu_0 K$ | 外部B=0 |

#### 7-7 带电粒子运动
- **回旋半径：** $r = \frac{mv_\perp}{|q|B}$
- **周期：** $T = \frac{2\pi m}{|q|B}$（与速度无关！）
- **螺距：** $h = v_\parallel T$
- **速度选择器：** $v = E/B$
- **质谱仪：** $m/q = B^2 r^2/(2U)$
- **回旋加速器：** $E_k = \frac{q^2 B^2 R^2}{2m}$
- **霍尔效应：** $U_H = \frac{IB}{nqt}$, $R_H = \frac{1}{nq}$

#### 7-8 安培力与磁力矩
- **载流导线：** $F = IL\times B$（均匀磁场中闭合线圈合力为零）
- **平行导线：** $F/l = \frac{\mu_0 I_1 I_2}{2\pi d}$，同向吸引，反向排斥
- **磁力矩：** $M = NISB\sin\theta$（θ是法线与B的夹角）
- **势能：** $U = -m\cdot B$，$m \parallel B$ 为稳定平衡

#### 7-9 磁介质
- $H = B/\mu_0 - M$，线性介质：$M = \chi_m H$
- $B = \mu_0\mu_r H$，$\mu_r = 1 + \chi_m$
- **类型：** 顺磁质($\mu_r > 1$)、抗磁质($\mu_r < 1$)、铁磁质($\mu_r \gg 1$)
- **标准流程：** 先求H → 再求 $B = \mu H$ → $M = \chi_m H$
- **同轴介质电缆：** $H = I/(2\pi r)$, $B = \mu I/(2\pi r)$

### 五、期末大题模板

**模板1：组合导线求B**
- 拆成若干段，逐段求B，矢量叠加
- 场点在直线段延长线上时贡献为零
- 圆弧用 $B = \mu_0 I\varphi/(4\pi R)$

**模板2：同轴电缆磁场**
- 按r分区，用安培环路定理
- 外部包围总电流为零，B=0

**模板3：长直导线旁矩形磁通**
$$\Phi = \frac{\mu_0 I l}{2\pi}\ln\frac{a+b}{a}$$
- 不能把B当匀强场

**模板4：带电粒子入匀强磁场**
- 分解速度，求r、f、h
- $r = \frac{mv\sin\theta}{|q|B}$, $f = \frac{|q|B}{2\pi m}$

**模板5：霍尔效应**
- $v = U_H/(Bd)$，或求n：$U_H = IB/(nqt)$

**模板6：磁介质求B,H,M**
- 先 $\oint H\cdot\mathrm{d}l = I_{自由}$ 得H
- 再 $B = \mu_0\mu_r H$, $M = (\mu_r - 1)H$

### 六、常见失分点

| 失分点 | 正确处理 |
|:---|:---|
| $\oint B\cdot\mathrm{d}l = 0$ 理解为 $B=0$ | 环流为零 ≠ 每点磁场为零 |
| 安培环路内无电流就无磁场 | 环路外电流也可产生B |
| 电子受力按正电荷判断 | 负电荷方向反向 |
| 圆周运动半径用v | 斜入磁场用 $v_\perp$ |
| 磁力矩夹角用错 | θ是磁矩m与B的夹角 |
| 磁介质直接套真空公式 | 优先用 $\oint H\cdot\mathrm{d}l = I_{自由}$ |

## 第八章 电磁感应 电磁场

### 一、知识框架

第八章的核心主线是：

> **磁通量变化 → 感应电动势/感应电场 → 电流变化产生自感互感 → 磁场储能 → 位移电流补全麦克斯韦方程**

| 模块 | 本质问题 | 核心公式 | 常见考法 |
|:---|:---|:---|:---|
| **8-1 电磁感应定律** | 什么情况下产生感应电动势？方向怎么判？ | $\varepsilon_i = -\frac{\mathrm{d}\Phi}{\mathrm{d}t}$, $\varepsilon_i = -N\frac{\mathrm{d}\Psi}{\mathrm{d}t}$ | 判断感应电流方向、线圈转动交流电动势 |
| **8-2 动生/感生电动势** | 来源是洛伦兹力还是变化磁场？ | $\varepsilon = \int (v\times B)\cdot\mathrm{d}l$, $\varepsilon = -\frac{\mathrm{d}\Phi}{\mathrm{d}t}$ | 导体棒切割、转动棒、圆盘发电机 |
| **8-3 自感与互感** | 电流变化如何反过来影响自身/别的线圈？ | $\varepsilon_L = -L\frac{\mathrm{d}i}{\mathrm{d}t}$, $\varepsilon_{21} = -M\frac{\mathrm{d}i_1}{\mathrm{d}t}$ | 求螺线管/同轴电缆自感、两线圈互感 |
| **8-4 磁场能量** | 磁场也是能量载体 | $W_m = \\frac{1}{2}LI^2$，$w_m = \\frac{B^2}{2\\mu_0}$ | 线圈储能、磁场能量密度、与电场能量密度比较 |
| **8-5 位移电流与麦克斯韦方程** | 变化电场也能激发磁场 | $I_d = \\varepsilon_0\\frac{\\mathrm{d}\\Phi_E}{\\mathrm{d}t}$, $\\oint H\\cdot\\mathrm{d}l = I_c + I_d$ | 平行板电容器充电磁场、位移电流概念、麦克斯韦积分方程 |

### 二、核心公式清单

| 公式 | 说明 | 易错点 |
|:---|:---|:---|
| $\varepsilon_i = -\frac{\mathrm{d}\Phi}{\mathrm{d}t}$ | 法拉第电磁感应定律 | 负号表示方向（楞次定律） |
| $\varepsilon_i = -N\frac{\mathrm{d}\Psi}{\mathrm{d}t}$ | N匝线圈 | $\Psi = N\Phi$ 为磁链 |
| $\varepsilon = \int (v\times B)\cdot\mathrm{d}l$ | 动生电动势 | $v\times B$ 的方向判断 |
| $\varepsilon_i = -\frac{\mathrm{d}\Phi}{\mathrm{d}t}$ | 感生电动势 | 由变化磁场产生 |
| $\varepsilon_L = -L\frac{\mathrm{d}i}{\mathrm{d}t}$ | 自感电动势 | L与电流无关 |
| $L = \frac{\Psi}{I}$ | 自感系数 | 只由几何和介质决定 |
| $\varepsilon_{21} = -M\frac{\mathrm{d}i_1}{\mathrm{d}t}$ | 互感电动势 | $M = M_{12} = M_{21}$ |
| $M = \frac{\Psi_{21}}{i_1}$ | 互感系数 | 与两线圈形状、位置有关 |
| $i = \frac{\varepsilon}{R}(1-e^{-t/\tau})$ | RL电路充电 | $\tau = L/R$ 时间常数 |
| $i = I_0 e^{-t/\tau}$ | RL电路放电 | 指数衰减 |
| $W_m = \frac{1}{2}LI^2$ | 线圈储能 | 与电容器储能 $\frac{1}{2}CU^2$ 类比 |
| $w_m = \frac{B^2}{2\mu_0}$ | 磁场能量密度 | 与电场 $w_e = \frac{1}{2}\varepsilon_0 E^2$ 类比 |
| $I_d = \varepsilon_0\frac{\mathrm{d}\Phi_E}{\mathrm{d}t}$ | 位移电流 | 变化电场等效为电流 |

### 三、解题方法

#### 1. 法拉第定律方向判断（4步法）

| 步骤 | 操作 | 目的 |
|:---|:---|:---|
| 1 | 任选一个回路绕行方向 | 给电动势正负定标准 |
| 2 | 用右手定则确定面积正法线方向 | 确定 $\Phi$ 的正负 |
| 3 | 判断 $\mathrm{d}\Phi/\mathrm{d}t$ 正负 | 看磁通量增大还是减小 |
| 4 | 用 $\varepsilon_i = -\mathrm{d}\Phi/\mathrm{d}t$ 判断方向 | $\varepsilon_i > 0$ 沿所选绕向，$<0$ 反向 |

**常见错误：** 还没规定正方向就直接说"顺时针/逆时针"

#### 2. 动生电动势

**产生条件：** 导体在磁场中做切割磁感线运动

**公式：** $\varepsilon = \int (v\times B)\cdot\mathrm{d}l$

**常见场景：**

| 模型 | 公式 | 说明 |
|:---|:---|:---|
| 直导体棒垂直切割磁感线 | $\varepsilon = Blv$ | $B,l,v$ 两两垂直 |
| 导体棒绕一端转动 | $\varepsilon = \frac{1}{2}B\omega l^2$ | 从转轴到端点积分 |
| 圆盘发电机 | $\varepsilon = \frac{1}{2}B\omega(R_1^2 - R_2^2)$ | 从内半径 $R_2$ 到外半径 $R_1$ 积分（盘心到盘边时 $R_2=0$） |
| 任意运动导线 | $\varepsilon = \int (v\times B)\cdot\mathrm{d}l$ | 不能直接套 $Blv$，需对路径积分 |
| 线圈在磁场中转动 | $\varepsilon = NBS\omega\sin\omega t$ | 交流发电机原理 |

**易错点：**
- ⚠️ 动生电动势的"非静电力"是洛伦兹力
- ⚠️ 公式中 $v$ 是导体相对于磁场的速度
- ⚠️ 只有切割磁感线的部分才产生电动势

#### 3. 感生电动势

**产生条件：** 磁场随时间变化（即使导体不动）

**核心概念：** 感生电场（涡旋电场）

- 感生电场线是闭合的，无头无尾
- $\oint E_{感}\cdot\mathrm{d}l = -\frac{\mathrm{d}\Phi}{\mathrm{d}t}$
- 与静电场不同，感生电场不是保守场

#### 4. 自感与互感

**1. 自感的定义**

$$L = \frac{\Psi}{I}$$

其中 $\Psi = N\Phi$ 是磁链（全磁通）。

自感电动势：
$$\varepsilon_L = -L\frac{\mathrm{d}I}{\mathrm{d}t}$$

若 $L$ 变化（如铁磁质、形变），应用更一般的公式：
$$\varepsilon_L = -\frac{\mathrm{d}(LI)}{\mathrm{d}t}$$

常见考题默认 $L$ 为常量。

**2. 自感的物理本质**

自感不是"阻碍电流"，而是**阻碍电流的变化**：

| 情况 | 自感电动势方向 | 效果 |
|:---|:---|:---|
| 电流增大 | 反抗增大，与原电流方向相反 | 减缓电流上升 |
| 电流减小 | 反抗减小，与原电流方向相同 | 减缓电流下降 |
| 电流恒定 | 无自感电动势 | 电感相当于短路（仅直流稳态） |

这也是 RL 电路中电流**不能突变**的根本原因。

**3. 自感计算模板**

| 步骤 | 操作 |
|:---|:---|
| 1 | 假设线圈中通电流 $I$ |
| 2 | 用安培环路定理或毕奥-萨伐尔定律求 $B$ |
| 3 | 求每匝磁通 $\Phi = \int B\cdot\mathrm{d}S$ |
| 4 | 求磁链 $\Psi = N\Phi$ |
| 5 | 用 $L = \Psi/I$ |

**关键：** $L$ 只与线圈形状、磁介质和匝数有关，与电流 $I$ 无关（无铁磁质时）。

**4. 典型自感公式**

| 模型 | 自感 | 参数说明 |
|:---|:---|:---|
| 长直密绕螺线管 | $L = \mu n^2 V = \mu\frac{N^2 S}{l}$ | $n$ 为单位长度匝数，$V = Sl$ 为体积 |
| 环形螺线管（截面很小） | $L \approx \mu\frac{N^2 S}{2\pi r}$ | $r$ 为平均半径，$S$ 为截面积 |
| 同轴电缆单位长度 | $L' = \frac{\mu}{2\pi}\ln\frac{b}{a}$ | $a$ 为内导体半径，$b$ 为外导体内半径 |
| 双线传输线单位长度 | $L' \approx \frac{\mu}{\pi}\ln\frac{d}{a}$ | $d$ 为两线间距，$a$ 为导线半径 |

**5. 互感的定义**

$$M_{21} = \frac{\Psi_{21}}{I_1}$$

互感电动势（线圈2中由线圈1的电流变化产生）：
$$\varepsilon_2 = -M\frac{\mathrm{d}I_1}{\mathrm{d}t}$$

**互感的对称性：**
$$M_{12} = M_{21} = M$$

但互感相等**不代表**两个线圈中的感应电动势大小相等，因为：
$$\varepsilon_1 = -M\frac{\mathrm{d}I_2}{\mathrm{d}t}, \quad \varepsilon_2 = -M\frac{\mathrm{d}I_1}{\mathrm{d}t}$$

若 $\dfrac{\mathrm{d}I_1}{\mathrm{d}t} \neq \dfrac{\mathrm{d}I_2}{\mathrm{d}t}$，则 $\varepsilon_1 \neq \varepsilon_2$。

**6. 互感大小由什么决定？**

| 因素 | 影响 |
|:---|:---|
| 两线圈匝数 | 匝数越多，一般互感越大 |
| 相对位置 | 同轴、靠近、磁通耦合强时大 |
| 夹角 | 面法线越接近平行，互感越大 |
| 磁介质 | 磁导率越大，一般互感越大 |
| 电流大小 | **不决定互感**，只影响磁通和感应电动势 |

> **课后题常问：**"互感与哪些因素有关？""怎样使互感较大？""两线圈位置如何影响互感？"——答案都在上表中。

**7. 求互感的通用步骤**

| 步骤 | 操作 |
|:---|:---|
| 1 | 在线圈1中通电流 $I_1$ |
| 2 | 求 $I_1$ 产生的磁场 $B_1$ |
| 3 | 求 $B_1$ 穿过线圈2的磁通 $\Phi_{21}$ |
| 4 | 磁链 $\Psi_{21} = N_2\Phi_{21}$ |
| 5 | $M = \Psi_{21}/I_1$ |

#### 5. 磁场能量
- 电感储能：$W_m = \frac{1}{2}LI^2$
- 能量密度：$w_m = \frac{B^2}{2\mu_0}$（真空）或 $w_m = \frac{B^2}{2\mu}$（介质）
- 场能积分：$W_m = \int w_m \mathrm{d}V$

#### 6. 位移电流与麦克斯韦方程

**位移电流：**
$$I_d = \varepsilon_0\frac{\mathrm{d}\Phi_E}{\mathrm{d}t}$$
- 位移电流的本质是变化电场
- 位移电流也能激发磁场（安培环路定理推广）
- 平行板电容器充电时，极板间存在位移电流

**麦克斯韦方程组（积分形式）：**

| 方程 | 物理意义 |
|:---|:---|
| $\oint E\cdot\mathrm{d}S = Q/\varepsilon_0$ | 静电场高斯定理（有源） |
| $\oint B\cdot\mathrm{d}S = 0$ | 磁场高斯定理（无源） |
| $\oint E\cdot\mathrm{d}l = -\frac{\mathrm{d}\Phi_m}{\mathrm{d}t}$ | 法拉第电磁感应定律 |
| $\oint B\cdot\mathrm{d}l = \mu_0 I + \mu_0\varepsilon_0\frac{\mathrm{d}\Phi_E}{\mathrm{d}t}$ | 安培环路定理（含位移电流） |

## 考前速查清单

### 第五章 静电场

- [ ] 库仑定律：$F = kq_1q_2/r^2$，方向沿连线
- [ ] 电场叠加：**矢量加法**，分解到分量
- [ ] 高斯定理：$\oint E\cdot\mathrm{d}S = Q_{内}/\varepsilon_0$，高度对称才用
- [ ] 常见电场：球面($r<R:0$)、球体($r<R:Qr/4\pi\varepsilon_0R^3$)、无限大平面($\sigma/2\varepsilon_0$)
- [ ] 电势：$V_P = -\int_\infty^P E\cdot\mathrm{d}l$ 或 $V = \int \mathrm{d}q/4\pi\varepsilon_0 r$
- [ ] 电势梯度：$E = -\nabla V$（负号！）
- [ ] 电势能：$W = qV$，电场力做功：$W_{ab}=q(V_a-V_b)$

### 第六章 导体与电介质

- [ ] 静电平衡：内部E=0，等势体，电荷表面分布
- [ ] 空腔导体：内表面电荷与腔内电荷等量异号
- [ ] 介质高斯定理：先求D再求E
- [ ] 电容：$C = Q/U$，串联($1/C$)、并联($C$)
- [ ] 平行板：$C = \varepsilon_0\varepsilon_r S/d$
- [ ] 能量：$W = Q^2/2C = CU^2/2$，密度 $w = \varepsilon E^2/2$
- [ ] Q不变($C\uparrow\to W\downarrow$)，U不变($C\uparrow\to W\uparrow$)

### 第七章 恒定磁场

- [ ] 毕奥-萨伐尔：$\mathrm{d}B = \mu_0 I\mathrm{d}l\times\hat{r}/4\pi r^2$
- [ ] 安培环路：$\oint B\cdot\mathrm{d}l = \mu_0 I_{内}$
- [ ] 常见B：无限长直导线($\mu_0I/2\pi r$)、圆心($\mu_0I/2R$)、螺线管($\mu_0nI$)
- [ ] 洛伦兹力：$F = qv\times B$，磁力不做功
- [ ] 回旋半径：$r = mv_\perp/|q|B$
- [ ] 安培力：$\mathrm{d}F = I\mathrm{d}l\times B$
- [ ] 磁力矩：$M = m\times B$，$m = NIS\hat{n}$
- [ ] 磁介质：先H→再B=$\mu$H→M

### 第八章 电磁感应

- [ ] 法拉第：$\varepsilon_i = -\mathrm{d}\Phi/\mathrm{d}t$，负号=楞次定律
- [ ] 动生：$\varepsilon = \int(v\times B)\cdot\mathrm{d}l$
- [ ] 自感：$\varepsilon_L = -L\mathrm{d}i/\mathrm{d}t$，$L = \Psi/I$
- [ ] 互感：$\varepsilon_{21} = -M\mathrm{d}i_1/\mathrm{d}t$
- [ ] RL电路：$i = (\varepsilon/R)(1-e^{-t/\tau})$充电，$i=I_0 e^{-t/\tau}$放电，$\tau=L/R$
- [ ] 磁场能量：$W_m = LI^2/2$，密度 $w_m = B^2/2\mu_0$
- [ ] 位移电流：$I_d = \varepsilon_0\mathrm{d}\Phi_E/\mathrm{d}t$
- [ ] 麦克斯韦方程组（积分形式）×4

### 总体易错点汇总

- 矢量运算注意**方向**（库仑力、电场强度、洛伦兹力、安培力）
- 高斯定理/安培环路定理的适用条件——**高度对称**
- 负电荷的洛伦兹力方向**反向**
- 有介质时**先求D再求E**
- 磁介质**先求H再求B**
- 感应电动势**先定正方向**再说顺时针/逆时针
- 能量题先判断**Q不变还是U不变**
- 位移电流是**变化电场**的等效，不是真的电荷流动
