## 一、运算符重载

### 1. operator+ 和 operator* 的标准写法

![](/images/cpp-review/01.jpg)

**黄金法则：** `operator+` 返回**新对象**，不修改 `this`；`operator+=` 才修改自身。

```cpp
// ✅ 正确：返回新对象，不修改 this
Jingshu operator+(const Jingshu& a, const Jingshu& b) {
    return Jingshu(a.yingdu + b.yingdu, a.weight + b.weight, a.volume + b.volume);
}

// ❌ 错误：修改了 this（左操作数），导致原对象被改变
Jingshu operator+(const Jingshu& other) {
    this->yingdu += other.yingdu;  // 改了 this！
    return *this;
}
```

**执行过程对比（你的代码）：**

初始 `js1 = 硬度3 重量3000 体积300`，执行 `js3 = js1 + js2`：

| 版本 | js1 在执行后的值 | js3 的值 |
|:---|:---|:---|
| ✅ 返回新对象 | 不变：3-3000-300 | 8-8000-800 |
| ❌ 修改 this | **被改：8-8000-800** | 8-8000-800 |

**第二个操作连续出错：** 若 `operator*` 也修改 `this`，`js1` 已在上一行被改为 `8-8000-800`，再乘 n 就是在被改过的值上操作，完全不是你预期的结果。

### 2. 四则运算符重载模板

```cpp
// 友元函数形式（推荐，支持隐式类型转换）
friend Jingshu operator+(const Jingshu& a, const Jingshu& b) {
    return Jingshu(a.yingdu + b.yingdu, a.weight + b.weight, a.volume + b.volume);
}

// 成员函数形式（this 是左操作数）
Jingshu operator+(const Jingshu& other) const {
    return Jingshu(this->yingdu + other.yingdu,
                   this->weight + other.weight,
                   this->volume + other.volume);
}
```

**为什么推荐友元？** 友元函数在参数中同时声明两个操作数，支持 `int + Jingshu` 这样的隐式转换。成员函数的左操作数必须是 `this` 类型。

### 3. 左值右值与运算符重载

| 表达式 | 类型 | 能否取地址 | 能否赋值 |
|:---|:---|:---:|:---:|
| `++a`（前置） | **左值** | ✅ | ✅ |
| `a++`（后置） | **右值** | ❌ | ❌ |
| `a + b` | **右值**（临时对象） | ❌ | ❌ |
| `a = b` | **左值** | ✅ | ✅ |

**为什么 `++a` 能链式调用但 `a++` 不行？**

```cpp
// 前置 ++：返回引用（左值）
Complex& operator++() {
    ++this->real;
    return *this;
}

// 后置 ++：返回临时对象（右值）
Complex operator++(int) {
    Complex temp = *this;
    ++this->real;
    return temp;  // 返回的是局部临时对象
}
```

**参数绑定规则（const 引用可以绑定到右值）：**
- `const Complex&` — 可以绑定到**任何值**（左值、右值、临时对象）
- `Complex&` — **只能**绑定到**左值**
- 所以 `operator+(const Complex&, const Complex&)` 可以接受 `a + b` 的结果作为参数

### 4. 流运算符重载：&lt;&lt; 和 &gt;&gt;

**必须使用友元函数**（因为左操作数是 `ostream`/`istream`，不是你自己的类）。

```cpp
// 输出运算符
friend ostream& operator<<(ostream& os, const Jingshu& j) {
    os << "硬度" << j.yingdu << "--重量" << j.weight << "--体积" << j.volume;
    return os;
}

// 输入运算符
friend istream& operator>>(istream& is, Jingshu& j) {
    // 跳过 "硬度" 前缀
    string tmp;
    getline(is, tmp, '-'); j.yingdu = stoi(tmp.substr(2));
    getline(is, tmp, '-'); j.weight = stoi(tmp.substr(2));
    getline(is, tmp, '-'); j.volume = stoi(tmp.substr(2));
    return is;
}
```

**关键注意：**
- `operator<<` 返回 `ostream&` 才能链式调用：`cout << a << b`
- 参数类型用 `const ClassName&`（不修改对象）
- `operator>>` 参数不用 const（要修改对象）

### 5. 前置 ++ 与后置 ++ 的区分

C++ 通过一个**哑元参数 `int`** 来区分：

```cpp
// 前置 ++
Date& operator++();       // ++d
// 后置 ++（int 是哑元，不传参）
Date operator++(int);     // d++
```

调用时编译器自动区分：`++d` 调用无参版本，`d++` 调用有 `int` 参数版本。

## 二、类设计与三/五法则

### 1. Rule of Three（三法则）

如果类需要**显式定义**以下三者中的任何一个，则三个都需要定义：

| 需要定义 | 何时触发 | 默认行为的问题 |
|:---|:---|:---|
| **析构函数** | 对象销毁时 | 指针成员只释放指针本身，不释放指向的内存 → **内存泄漏** |
| **拷贝构造函数** | 传值、返回对象、`Class b = a` | 浅拷贝 → 两个对象的指针指向同一块内存 → **double free** |
| **拷贝赋值运算符** | `a = b` | 同上 + 原对象内存泄漏 |

```cpp
class CVector {
private:
    int* data;
    int size;
public:
    // 构造函数
    CVector(int n) : size(n) {
        data = new int[size]();
    }
    // 析构函数
    ~CVector() { delete[] data; }
    // 拷贝构造函数（深拷贝）
    CVector(const CVector& other) : size(other.size) {
        data = new int[size];
        for (int i = 0; i < size; i++) data[i] = other.data[i];
    }
    // 拷贝赋值运算符
    CVector& operator=(const CVector& other) {
        if (this != &other) {
            delete[] data;           // 释放旧资源
            size = other.size;
            data = new int[size];    // 分配新资源
            for (int i = 0; i < size; i++) data[i] = other.data[i];
        }
        return *this;
    }
};
```

### 2. 赋值运算符的通用框架

```cpp
Class& operator=(const Class& other) {
    if (this != &other) {          // 1. 自赋值检查
        // 释放旧资源
        delete[] data;
        // 分配新资源 + 拷贝
        size = other.size;
        data = new int[size];
        memcpy(data, other.data, size * sizeof(int));
    }
    return *this;                   // 3. 返回 *this
}
```

### 3. 构造函数中的常见陷阱

**陷阱1：构造函数读取 cin（OJ 中的严重 bug）**

如果类的构造函数里写了 `cin >> x`，那么：
- 在 `main` 函数外创建 `Result` 对象 → **吃掉一行输入**
- 在 `operator+` 内创建临时对象 → **又吃掉一行输入**
- 后续的 `cin` 读到的是错误的数据

```cpp
// ❌ 错误：构造函数读取输入
class CBigInteger {
public:
    CBigInteger() {
        cin >> str;  // 每次创建对象都读输入——灾难！
    }
};

// ✅ 正确：构造函数只初始化，输入单独处理
class CBigInteger {
public:
    CBigInteger() : str("") {}
    CBigInteger(const string& s) : str(s) {}
    void input() { cin >> str; }
};
```

**陷阱2：`=` 与 `==` 混淆**

```cpp
// ❌ 错误（构造函数中）
Cryption(const Cryption& other) {
    data = other.data;    // 这行编译通过，但不是拷贝的逻辑
}

// ❌ 常见低级错误
if (n = 0)  // 赋值，不是比较！永远为 false
if (n == 0) // 这才是比较
```

**陷阱3：未初始化的成员变量**

```cpp
class Foo {
    int a;       // 未初始化 → 随机值！
    int b = 0;  // ✅ C++11 就地初始化
public:
    Foo() : a(0) {}  // ✅ 初始化列表
};
```

### 4. 拷贝构造函数的调用时机

```cpp
void func(Class obj);           // 传值 → 拷贝构造
Class ret() { return obj; }     // 返回对象 → 拷贝构造
Class a = b;                    // 初始化 → 拷贝构造
a = b;                          // 赋值 → 不是拷贝构造，是 operator=
```

**深度思考题：**
```cpp
// 先读入一个数，用来构造对象
int n; cin >> n;
CBigInteger arr[3];  // 这里调用了 3 次默认构造函数
```

如果默认构造函数里写了 `cin >> str`，那么定义 `arr[3]` 时会连读 3 次输入——导致输入顺序完全错乱。

## 三、C++ 字符串与输入处理

![](/images/cpp-review/02.jpg)

### 1. cin >> vs getline

```cpp
// cin >> 读到空白（空格、tab、换行）停止
int n; cin >> n;          // 读整数，回车留在缓冲区
string s; cin >> s;       // 读字符串，遇空格停

// getline 读到换行符停止
getline(cin, s);          // 读一整行

// 混合使用的陷阱
int n; cin >> n;          // 输入 "42\n"，读取 42，留下 '\n'
getline(cin, s);          // 直接读到 '\n'，s 为空字符串！
```

**解决方案：用 `cin.ignore()`**
```cpp
int n; cin >> n;
cin.ignore();             // 丢弃缓冲区的 '\n'
getline(cin, s);          // 现在正确读取下一行
```

### 2. C++ string 常用操作

```cpp
#include <string>
using namespace std;

string s = "hello";
s.length();               // 长度
s.size();                 // 同 length
s.substr(pos, len);       // 取子串
s.find("world");          // 查找，返回下标或 string::npos
s.rfind('x');             // 从右向左查找
s.insert(pos, "abc");     // 插入
s.erase(pos, len);        // 删除
s.replace(pos, len, str); // 替换
to_string(123);           // 数字转字符串
stoi("456");              // 字符串转 int
stod("3.14");             // 字符串转 double
```

### 3. C 风格字符串 vs C++ string

```cpp
// C 风格（不推荐）
char str[100];
strcpy(str, "hello");
strcmp(str, "world");

// C++ 风格（推荐）
string s = "hello";
if (s == "world") ...
string t = s + "!";
```

**OJ 注意事项：** 大部分 OJ 题目允许使用 C++ string，但某些老题目可能要求 C 风格。看题目是否 `#include <string>` 或需要 `cstring`。

### 4. 格式化输出

```cpp
#include <iomanip>

double pi = 3.1415926;
cout << fixed << setprecision(2) << pi;     // 3.14
cout << setw(10) << setfill('0') << 42;     // 0000000042
cout << left << setw(10) << "hello";        // hello     （左对齐）

// 恢复默认
cout << defaultfloat;                       // 恢复默认浮点格式
cout << setprecision(6);                    // 恢复默认精度
```

**OJ 常见格式要求：**
- 保留 N 位小数：`fixed << setprecision(N)`
- 输出宽度：`setw(W)`
- 对齐方式：`left` / `right`
- 填充字符：`setfill('c')`

### 2. 高频题型详解

#### 题型1：CBigInteger（大整数类）

用字符串存储超过 `long long` 范围的整数，实现加减乘除。

```cpp
class CBigInteger {
private:
    string data;              // "123456789..."
    bool isNegative;          // 符号位
public:
    CBigInteger() : data("0"), isNegative(false) {}
    CBigInteger(const string& s) { /* 解析符号和数字 */ }

    friend CBigInteger operator+(const CBigInteger& a, const CBigInteger& b);
    friend CBigInteger operator-(const CBigInteger& a, const CBigInteger& b);
    friend ostream& operator<<(ostream& os, const CBigInteger& n) {
        if (n.isNegative) os << '-';
        os << n.data;
        return os;
    }
    friend istream& operator>>(istream& is, CBigInteger& n) {
        is >> n.data;
        return is;
    }
};
```

**核心算法：** 从低位到高位逐位相加/相减，处理进位/借位。

#### 题型2：RMB（货币类）

用整数存储"分"避免浮点精度问题。

```cpp
class RMB {
private:
    long long fen;  // 以"分"为单位存储
public:
    RMB(double yuan) : fen((long long)(yuan * 100 + 0.5)) {}
    RMB operator+(const RMB& other) const {
        return RMB(0, fen + other.fen);  // 内部用分的构造
    }
    // 输出两位小数
    friend ostream& operator<<(ostream& os, const RMB& r) {
        os << r.fen / 100 << "." << setw(2) << setfill('0') << r.fen % 100;
        return os;
    }
};
```

#### 题型3：CVector（向量/矩阵类）

动态数组，需要深拷贝（Rule of Three）。

```cpp
class CVector {
private:
    int* data;
    int size;
public:
    CVector(int n);                    // 构造函数
    ~CVector();                        // 析构函数
    CVector(const CVector& other);     // 拷贝构造
    CVector& operator=(const CVector& other); // 赋值运算符

    int& operator[](int index);        // 下标访问
    const int& operator[](int index) const; // const 版本

    CVector operator+(const CVector& other) const; // 向量加法
    int operator*(const CVector& other) const;      // 内积
};
```

**关键细节：**
- `operator[]` 返回**引用**才能被赋值：`v[0] = 5;`
- 需要 const 和 非 const 两个版本
- 内积是对应位置相乘再求和

#### 题型4：Jingshu 类（综合运算符重载）

典型的综合题型，覆盖 `+`, `*`, `<<`, `>>`, `++`, `--`。

```cpp
class Jingshu {
private:
    int yingdu, weight, volume;
public:
    // 各类运算符
    friend Jingshu operator+(const Jingshu& a, const Jingshu& b);
    friend Jingshu operator*(const Jingshu& a, int n);
    friend Jingshu operator*(int n, const Jingshu& a);  // 对称版本
    Jingshu& operator++();           // 前置++
    Jingshu operator++(int);         // 后置++
    friend ostream& operator<<(ostream& os, const Jingshu& j);
    friend istream& operator>>(istream& is, Jingshu& j);
};
```

### 3. OJ 常见失分点

| 失分点 | 原因 | 解决方法 |
|:---|:---|:---|
| **格式错误** | 多空格、少换行、系数 ±1 显示问题 | 严格按样例输出 |
| **构造函数读 cin** | 创建临时对象时吃掉输入 | 构造函数只初始化 |
| **operator+ 修改 this** | 左操作数被改变 | 返回新对象 |
| **浅拷贝** | 指针成员不带深拷贝 | 实现三法则 |
| **未加 const** | 临时对象绑定不到非 const 引用 | 参数加 const，方法加 const |
| **自赋值未检查** | `a = a` 时先 delete 再 new → 数据丢失 | `if (this != &other)` |
| **-0 问题** | 输出 "-0" 而非 "0" | 特判 0 |

### 5. 高阶技巧：由 main 函数反推类设计

拿到题目后，先不要急着看描述，**先看 main 函数**：

```cpp
int main() {
    int n1, n2, n3;
    cin >> n1 >> n2 >> n3;

    Cryption<int> c1(5);         // 模板类，参数是 int
    Cryption<int> c2 = c1;       // 需要拷贝构造函数
    Cryption<double> c3(3.14);   // 模板参数为 double

    cout << c1.max(c2) << endl;  // 成员函数 max，返回较大的那个
    cout << Max(n1, n2) << endl; // 函数模板 Max

    return 0;
}
```

**反推结果：**
- `Cryption<T>` 是类模板
- 需要：构造函数（单参）、拷贝构造函数、`max()` 成员函数
- `Max(T a, T b)` 是函数模板

## 五、模板编程

### 1. 函数模板

```cpp
// 函数模板定义
template <typename T>
T Max(T a, T b) {
    return a > b ? a : b;
}

// 调用
cout << Max(3, 5) << endl;      // T = int
cout << Max(3.14, 2.71) << endl; // T = double
cout << Max('a', 'b') << endl;   // T = char
```

### 2. 类模板

```cpp
template <typename T>
class Cryption {
private:
    T data;
public:
    Cryption(T d) : data(d) {}
    Cryption(const Cryption<T>& other) : data(other.data) {}

    T getData() const { return data; }
    Cryption<T> max(const Cryption<T>& other) const {
        return data > other.data ? *this : other;
    }
};
```

### 3. 模板常见错误

```cpp
// ❌ 错误：类模板是模板，不是类型
Cryption c1(5);   // 必须指定模板参数

// ✅ 正确
Cryption<int> c1(5);

// ❌ 错误：模板参数不匹配
Cryption<int> c1(5);
Cryption<double> c2(3.14);
c1.max(c2);        // 类型不同，编译错误
```

## 六、继承与多态

![](/images/cpp-review/04.jpg)

### 1. 继承的基本语法

```cpp
class Base {
protected:
    int a;
public:
    void func() { cout << "Base" << endl; }
    virtual void vfunc() { cout << "Base virtual" << endl; }
};

class Derived : public Base {
public:
    void func() { cout << "Derived" << endl; }    // 隐藏（hide）
    void vfunc() override { cout << "Derived override" << endl; }  // 覆盖（override）
};
```

### 2. virtual、override、多态

```cpp
Base* p = new Derived();
p->func();        // 调用 Base::func（编译时绑定）
p->vfunc();       // 调用 Derived::vfunc（运行时绑定，多态！）
```

**虚函数表机制：**
- 有虚函数的类有一个虚函数表（vtable）
- 对象中有一个 vptr 指向 vtable
- 调用虚函数时：通过 vptr → vtable → 函数指针，运行时决定调用哪个函数

### 3. 纯虚函数与抽象类

```cpp
class Actor {
public:
    virtual void act() = 0;   // 纯虚函数
    virtual ~Actor() {}        // 虚析构（重要！）
};

class Hero : public Actor {
public:
    void act() override { cout << "Hero acts" << endl; }
};
```

**纯虚函数的特点：**
- 包含纯虚函数的类不能实例化（抽象类）
- 派生类必须实现所有纯虚函数才能实例化
- 用于定义接口规范

### 4. 虚析构函数

```cpp
class Base {
public:
    // virtual ~Base() {}  // 如果缺少这行
};

class Derived : public Base {
    int* data;
public:
    Derived() { data = new int[100]; }
    ~Derived() { delete[] data; }  // 不会被执行！
};

int main() {
    Base* p = new Derived();
    delete p;  // 如果 Base 析构非虚，不会调用 ~Derived() → 内存泄漏！
}
```

**规则：** 如果类可能被继承，析构函数应该声明为 `virtual`。

## 七、C++ 的 union 与类型转换

### 1. union 类型

```cpp
union Data {
    int i;
    float f;
    char str[4];
};

Data d;
d.i = 42;        // 现在存储 int
cout << d.f;      // 按 float 解释同一块内存（未定义行为！）
```

**union 注意：**
- 所有成员共享同一块内存
- 大小为最大成员的大小
- C++11 起 union 可以包含有构造函数/析构函数的成员（但需要手动管理）

### 2. 类型转换

```cpp
// 隐式转换（编译器自动）
int a = 3.14;       // double → int，丢失小数

// 显式转换（C 风格）
double b = (double)3 / 2;  // 1.5

// C++ 风格
double c = static_cast<double>(3) / 2;  // 推荐

// 多跳转换限制
// char → int → double 可以（隐式逐级转）
// 不能从自定义类型 A 直接转到不相关的类型 B（除非定义了转换运算符）
```

## 八、OJ 题型综合分类

根据 OJ 题库分析，C++ 程序设计常见题型分为以下几类：

### 1. 基础类设计（占比 ~30%）

| 题型 | 核心要求 | 关键点 |
|:---|:---|:---|
| **RMB/货币类** | 避免浮点精度，用整数存"分" | 输入解析、格式化输出 |
| **时间/Date类** | 运算符重载 + - ++ -- | 进位/借位处理、输出格式 |
| **分数 Fraction** | 约分、通分、四则运算 | gcd、负数处理、=0 特判 |
| **复数 Complex** | 四则运算 + 流运算符 | 虚部 i 的处理 |

### 2. 大数运算（占比 ~20%）

| 题型 | 核心要求 | 关键点 |
|:---|:---|:---|
| **CBigInteger** | 字符串模拟大数加减乘 | 对齐位数、处理进位/借位、符号 |
| **N 进制运算** | 转换为十进制运算再转回 | 进制转换方法 |

### 3. 容器与动态数组（占比 ~20%）

| 题型 | 核心要求 | 关键点 |
|:---|:---|:---|
| **CVector** | 深拷贝，Rule of Three | 拷贝构造、赋值运算符 |
| **CMatrix** | 二维动态数组 | 下标访问、矩阵乘法 |
| **多项式类 Poly** | 系数数组存储 | poly[i] 表示 i 次项系数 |

### 4. 模板与综合（占比 ~15%）

| 题型 | 核心要求 | 关键点 |
|:---|:---|:---|
| **Cryption&lt;T&gt;** | 类模板 + 函数模板 Max | 模板参数推导 |
| **泛型容器** | 模板+运算符重载 | const 正确性 |

### 5. 字符串处理与格式化（占比 ~15%）

| 题型 | 核心要求 | 关键点 |
|:---|:---|:---|
| **字符串解析** | 根据格式解析数字/命令 | getline + stringstream |
| **格式化输出** | setw、fixed、setprecision | 对齐、填充、小数位数 |
| **表达式解析** | 递归解析嵌套表达式 | 括号匹配、递归下降 |

## 附：考前速查清单

### 运算符重载

- [ ] `operator+` 返回**新对象**，不修改 `this`
- [ ] `operator+=` 返回 `*this`（引用）
- [ ] 前置 `++` 返回引用，后置 `++` 返回临时对象 + 哑元 `int`
- [ ] `<<` / `>>` 必须是**友元**，返回 `ostream&` / `istream&`
- [ ] 友元支持隐式类型转换，成员函数不支持
- [ ] `const Class&` 参数可绑定右值（临时对象）

### 类设计

- [ ] 指针成员 → **Rule of Three**（析构、拷贝构造、赋值运算）
- [ ] 赋值运算符：**自赋值检查** `if (this != &other)`
- [ ] 构造函数**不要读 cin**
- [ ] 初始化列表优先于构造函数体内赋值
- [ ] 虚析构函数（基类）

### OJ 提交前检查

- [ ] 输出格式与样例**完全一致**（空格、换行、大小写）
- [ ] 系数 ±1 显示：`1x^2` 不是 `1x^2`，`-x` 不是 `-1x`
- [ ] 不要输出 `-0` → 特判 0
- [ ] 构造函数不读输入
- [ ] `operator+` 不修改操作数
- [ ] 所有方法正确标注 `const`
- [ ] 数组不越界
- [ ] 变量已初始化
