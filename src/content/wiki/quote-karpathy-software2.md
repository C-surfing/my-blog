# Quote: Karpathy — Software 1.0 vs Software 2.0

> 原文：[Software 2.0](https://karpathy.medium.com/software-2-0-a64152b37c35)（Andrej Karpathy, 2017）

> In Software 1.0, we write the rules. In Software 2.0, we write the goal and the data, and the optimizer figures out the implementation.

**我的想法**：2017 年的说法，现在依然是最好的"为什么要用神经网络"的一句话回答。做 Agent 工程时这个二分有个延伸：Agent 系统本身也是 2.0 思维——与其手写每一步的决策逻辑，不如定义好目标、工具面与反馈信号，让模型在运行时自己规划。当年 Karpathy 说"神经网络是可编译的软件"，今天的 prompt + 工具 + 记忆，就是 Agent 时代的 Software 2.0 编译产物。
